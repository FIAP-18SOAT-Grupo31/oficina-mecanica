# Diagramas C4

O modelo C4 descreve a arquitetura em níveis de zoom. Aqui estão os dois primeiros: quem usa o sistema (contexto) e as partes que rodam (contêineres).

## Nível 1: contexto

```mermaid
flowchart TB
    funcionarios["Atendente, Mecânico e Admin<br/>funcionários da oficina"]
    cliente["Cliente da oficina<br/>acompanha e aprova a OS"]
    sistema["Sistema da Oficina<br/>ordens de serviço, orçamentos e estoque"]

    funcionarios -- "gerenciam OS, clientes, veículos, serviços e peças (com JWT)" --> sistema
    cliente -- "consulta o andamento e aprova o orçamento (rotas públicas, a implementar)" --> sistema
```

## Nível 2: contêineres

```mermaid
flowchart TB
    usuarios["Funcionários e clientes"]

    subgraph compose["docker compose"]
        api["API REST<br/>Java 21, Spring Boot 4"]
        db[("PostgreSQL 16")]
        pgadmin["pgAdmin"]
    end

    usuarios -- "HTTP/JSON, documentado no Swagger" --> api
    api -- "JDBC, schema versionado pelo Flyway" --> db
    pgadmin -- "consulta" --> db
```
