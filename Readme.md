# ⚙️ Sistema Integrado - Oficina Mecânica (Em Desenvolvimento)

> **Aviso:** Este repositório contém um projeto em desenvolvimento para o **Tech Challenge (Fase 1)** do curso de pós-graduação da FIAP.

## 📖 Contexto do Projeto

Uma oficina mecânica de médio porte precisa modernizar os seus processos para expandir os serviços com qualidade e eficiência. Atualmente, o atendimento, o diagnóstico e a execução de serviços são feitos de forma desorganizada através de planilhas e anotações manuais, o que gera problemas no controle de peças, priorização de atendimentos e no fluxo de orçamentos.

Este projeto propõe o desenvolvimento da primeira versão (MVP) do back-end de um Sistema Integrado de Atendimento e Execução de Serviços.

## 🎯 Objetivos Principais

* Construir um back-end monolítico organizado em camadas, aplicando táticas de Domain-Driven Design (DDD).
* Gerenciar todo o fluxo de uma Ordem de Serviço (OS), desde a identificação do cliente e veículo, inclusão de peças/serviços, até a geração automática do orçamento e alteração de status.
* Disponibilizar APIs RESTful para a gestão administrativa (CRUDs de clientes, veículos, serviços e peças com controle de estoque).
* Garantir a segurança das APIs administrativas através de autenticação JWT.

## 🛠️ Stack Tecnológica (Definição Inicial)
* Java 21
* Spring Boot 4
* PostgreSQL
* Docker & Docker Compose
